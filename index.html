Install WalletZen
Android (Chrome)
Tap the ⋮ menu → Install app (or Add to Home screen).
iPhone / iPad (Safari)
Tap the Share button → Add to Home Screen → Add.
Desktop (Chrome / Edge)
Click the install icon in the address bar, or menu → Install WalletZen.
Note: install needs the app to be opened from a secure web address (https) — for example Netlify, GitHub Pages or Vercel. It will not install when opened directly as a local file.
